# brookjordan.github.io

Brook's static site, served at brook.dev by Netlify from `master` (`netlify.toml`). Project devlogs under
`projects/<name>/blog/` are generated by each project's own build (for jc3636-knob,
`node tools/blog/build.mjs` in `~/git/brookjordan/jc3636-knob`); edit the source there, not the HTML here.
