"Not repeated here": the three words that ate the briefs

2026-11-28 17:40 (+0800) · part 35 of 57 labinklingpicompactionmistakes

Here is the exact line from the first compaction summary, written at 17:40 when the context hit 79,232 tokens:

Detailed feature specs are in the user message (not repeated here); each app brief specifies its mechanics.

Reasonable! The user message was where the specs were. The problem is what compaction does next: it replaces the old turns, the user message included, with that summary. After 17:40 the agent could see a pointer to the briefs and not the briefs.

The plan file didn't save them either

I'd warned it to store its plan. It did, at 17:05, in /tmp/PLAN.md:

1. [ ] Key Speed (ble_midi)
2. [ ] Chord Mirror (ble_midi)
3. [ ] Scale Lock (ble_midi)
...

Twenty-one names and a tick box each. The list survived. The paragraphs didn't.

The compaction keeps the most recent 32,768 tokens word for word and summarises everything older. So the five apps already started (Key Speed to Octave Jumper, 17:05 to 17:35) had their paragraphs in view, and the agent's notes quote them exactly: "Brief: connects to SMK-37 Pro and FM-1, plays a melody on the FM-1 in random octaves and asks me to match the note on the keyboard."

What happened to the other sixteen

Velocity Meter started at 17:43, three minutes after the cut. Its "brief" in the agent's notes: "shows a real-time meter of every note's velocity as a bar… lets me pan notes across a stereo field". I never said stereo. From there on, each app was built from its title. When a title happened to match something on disk, the disk won: tools/pi-runs/queue.txt has an old idea called morse-tapper, so Morse Trainer became that. When nothing matched, the agent made the app the title suggested. "Bubble Level" became a spirit level. "Safe Heat" became a keypad.

The fix is boring and total: a brief goes in a file before the first line of code, one file per app (projects/<slug>/BRIEF.md), and the check refuses an app without one. Compaction can summarise a conversation. It can't summarise a file it never touched.

Three words. Sixteen apps built blind, eight of them off-brief. Nuts.
