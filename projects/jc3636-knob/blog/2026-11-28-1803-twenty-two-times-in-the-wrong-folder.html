Twenty-two times in the wrong folder

2026-11-28 18:03 (+0800) · part 37 of 57 labinklingpishellmistakes

Here's a command the agent loved:

cd projects/safe-heat/main && python3 - <<'EOF' ... EOF
tools/check.sh safe-heat

Edit the file from inside the app's folder, then run the check. Except tools/check.sh lives at the repo root, and the shell is now three folders down. Every time:

/bin/bash: tools/check.sh: No such file or directory

Then it would run the check again, correctly, from the root. Fine. One wasted call.

Twenty-two wasted calls

Counted from the session: 22 of those errors between 17:16 and 18:58. The best bit is the second compaction summary, at 18:03, which had learned the lesson and written it down under Constraints & Preferences:

Run tools/check.sh from repo root, not from projects/<app>/main (fails with "No such file or directory").

It then did it again on Compass Spinner, Orbit Dodge (three times), Asteroid Cannon, Colour Match (twice), Safe Heat (three times) and Morse Trainer. The rule was in the context the whole time. The habit was stronger.

What the retro made of it

Retry #16 in the agent's own retro: "Build check failures from tools/check.sh run outside repo root | re-run from root | always cd to repo root." One row, as if it happened once and was fixed. It's the single most repeated mistake of the night.

The boring fix

The AGENTS.md says "Run every command from the repo root". Telling the model a thing it had already written down did nothing here; making the mistake impossible would. The failure isn't inside check.sh, it's the shell not finding check.sh at all, so:

  • tools/pi.sh could put the repo's tools/ on PATH, so check.sh safe-heat works from any folder. check.sh already finds its own root (ROOT=${0:A:h:h}), so nothing else changes.
  • Or pi's tool wrapper could refuse a cd inside a chained command. Harsher, but it would also stop the sed: projects/morse-trainer/main/main.c: No such file or directory cousin, which happened too.

The first is kinder. Twenty-two calls is about four minutes at this run's pace. Not a disaster. Just a very determined pigeon.
