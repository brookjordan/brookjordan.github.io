Docs that were there all along, and the four that weren't

2026-11-28 21:45 (+0800) · part 52 of 57 labdocsinklingskills

When a small model trips, the retro's reflex is "the doc should say X". Sometimes it should. Often it does. Tonight's list, split honestly:

Already written down

Tripped on Where it already was
leds_set_all doesn't exist game-template.md line 18: leds_set, leds_fill, leds_show
TEXT_XL can't draw letters (Octave Jumper's "G3", Morse's "K") line 16: XL: digits and : - + % / . ! ? x only
DEG_TO_RAD re-defined in 5 apps line 17: polar(), angle_of(), angle_diff(), "Use these instead of writing your own"
random targets break the test line 61: in the sim it is seeded, so runs repeat
FM-1 sends dropped knob-ble-midi example connects both slots
board "needs replug" knob-flash: --after watchdog-reset
5 apps skipped launcher.py line 196

The agent read all four of the main docs between 17:04 and 17:05, in the first ninety seconds. Then it built for two hours and compacted six times. Reading a doc at the start of a long run is like reading the manual in the shop: you remember there was a manual.

Real gaps

  1. sfx_play volume is 0 to 1. The doc gives the signature, not the range. Key Speed passed 90. The simulator caught it ("vol 90.00 is outside 0..1"), which is the system working, but one word in the doc saves the round trip.
  2. -Werror=format-truncation. GCC can't always prove a %d fits a small buffer. One line in the doc: size text buffers at 32.
  3. The long press is fixed at 600 ms, in ui.c. Fine for every game so far. Worth a sentence so nobody hunts for the setting.
  4. ble_midi_smk_label() means slot 0. That's a naming problem more than a doc problem (the post).

The lesson for the docs

More docs probably won't fix the first table. The fixes there are at the point of the mistake: the compiler error for leds_set_all could say "see leds_fill"; the simulator's TEXT_XL warning already says "use TEXT_L", and the agent fixed both cases in one go because of it. That's the pattern that worked all night: the warning that names the fix. The simulator's warnings did more teaching tonight than every doc together.
