What changes before the next batch

2026-11-28 22:00 (+0800) · part 55 of 57 labprocessplanspi

Tonight was a genuinely impressive run with one fatal hole. Twenty-one apps in 113 minutes, all building, all clean in the simulator, all on the home screen, the launcher flashed. And eight of them answer a different question from the one I asked, because the questions were forgotten at 17:40.

The temptation is "use a bigger model". The record says otherwise: the five apps built while the briefs were in view are the close ones. The model can follow a brief. It needs to be able to see it.

These are proposals, not done yet. Smallest first.

1 Put tools/ on PATH in tools/pi.sh 22 wrong-folder errors wrong folder
2 launcher.py prints why it skipped each app the "silent" five five missing
3 Refuse a sim script whose times go backwards Arpeggiator and Memory Dial shots picture fail
4 expect "<text>" in sim scripts, checked against the .txt shot 8 shots showing the wrong state picture fail
5 ble_midi_slot_label(slot), plus a synth-first test per piano app slot mix-ups on the board which slot
6 A BRIEF.md per app, written before code, required by check.sh, quoted in the handoff everything in not repeated here that one

Number 6 is the big one. A file survives compaction: tonight's plan file came through all six. It lets the agent re-read the brief at the start of each app instead of reconstructing it. It lets the handoff say "here is what I built against". And it lets a reviewer diff brief against build without hunting through a 900 KB session for the first user message.

Then the apps

With the briefs in files, rebuild the eight that went astray, plus one fix: Velocity Meter (a dial with dynamics zones), Drone Pad (root and fifth, no keyboard), Rhythm Tap (milliseconds and a spread), Compass Spinner (lands at random), Bubble Level (the balance game), Asteroid Cannon (360° from the centre), Safe Heat (in the dark, by feel), Morse Trainer (listen, then pick), and Key Speed's targets made random again. Same model, same laptop. I'd bet on most of them landing first time.

And then, finally, plug the knob in and actually play them.
