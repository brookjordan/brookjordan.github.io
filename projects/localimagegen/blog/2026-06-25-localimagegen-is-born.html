localimagegen is born — one repo to rule the matrix

2026-06-25 · milestone architecture decision

The image-model comparison work had outgrown a pile of ad-hoc Python scripts living in docker-stacks/patch-notes-image-research/run/ and the ComfyUI output folder (_sweep_lib.py, reconcile.py, normalize_grid.py, stage2_tools.py, fixed/*.py, …). State was scattered across filenames, scripts, and a monolithic index.html. This entry records why we extracted it all into a single Node repo.

What the machine makes when it's behaving — Qwen-Image 2512, "dragon", 10 steps. This is the carrot at the end of all the plumbing below.

Why a rewrite (and why Node)

  • The gallery is already JavaScript; the orchestration was Python. Unifying on Node (>=20, native fetch, sharp, ssim.js, yaml) means one language, one toolchain.
  • One config as the single source of truth (config/gallery.yaml) instead of constants spread across several scripts.
  • The masters are the real artefact, so they live in the repo (committed, ~1.1 GB) rather than only in a ComfyUI output dir that SMB has been known to eat.

The tenets we committed to

  • Convergent, crash-only. Desired state = config; actual state = a scan of masters/. Every command recomputes the diff and is idempotent. Pause = Ctrl-C, resume = re-run. No fragile run-state file to corrupt.
  • Priority tiers. run fills missing -> invalid -> deprecated, so coverage beats refinement. Fastest models first, one model at a time, freeing VRAM between.
  • Deprecation, not deletion. Editing a prompt changes its promptHash, which auto-deprecates affected cells; they re-render after all gaps. Old images keep serving until a validated replacement is atomically swapped in.
  • One web source, two builds. web/app.{html,css,js} bakes into a fixed page (data inlined, offline-capable) and a flexible page (fetches data/ at runtime).
  • Self-validating. A sharp-based gate rejects corrupt/blank/wrong-dim renders before they count as "done".

Outcome

All 13 plan todos done. Engine in src/, config-driven, masters committed, gallery builds + publishes to brook.dev/projects/localimagegen — first commit at 16:44 on the 25th. Next up: render the new kingdom scene and let the autopilot (run --watch) catch up seed 2026.
