The great lossless-WebP scare (or: the monster that wasn't)

2026-06-25 22:30 · decision ops lesson

Gather round, for a tale of terror. 🦖

It began, as these things do, with a number. The masters/ folder — every original render, the canonical source of truth — weighed 1.1 GB. Someone (fine, it was me) muttered the cursed words: "lossless WebP is supposed to be about 30% smaller…"

And then the fears arrived, one by one, like crows on a fence.

Fear the first — compatibility. WebP? For masters? The archival source?! What if some tool down the line can't read it? What if future-me opens a master and gets a sad broken-image icon?

Fear the second — "lossless," sure. Everyone says lossless. But would it really be bit-for-bit identical, or would some sneaky chroma-subsampling gremlin shave off a pixel here, a shade there, and quietly degrade a thousand images while I wasn't looking?

Fear the third — the ritual. To actually reclaim the space, the bytes already live in git history. That means… rewriting history. filter-repo. A force-push. To a repo I'd pushed to GitHub barely an hour earlier. The kind of sentence that makes your palms sweat.

So we prepared like doomsday preppers. Three backups: the original 1,026 PNGs still sitting untouched in the ComfyUI output folder, a full git bundle snapshot, and a pre-webp-migration tag. The migration script verified every single file was pixel-identical (decode both, compare raw buffers) before it was allowed to delete a single PNG. Belt, braces, and a second pair of braces for the braces.

Tension mounting. Drumroll. Fingers hovering. We ran it.

…

It worked. 1026 / 1026 converted. 0 failures. Every pixel identical. 1167 MB → 834 MB, 28.6% smaller, exactly as promised. sharp/libvips didn't so much as blink. The engine (status, compress, verify) treated the .webp masters precisely like the PNGs — done: 1026, no code drama. The scary history rewrite? Mechanical. The force-push? Boring.

The monster was a coat on a chair.

The lesson. Lossless WebP is lossless and is mature — the "compatibility" dread was vibes, not fact. The only thing standing between us and a free ~30% was being scared of it. And the reason the scary part was boring is the part that's actually worth keeping: **verify-before-delete

  • real backups turn an irreversible-looking operation into a reversible one.** Do that, and you get to be brave for free.

Anyway. Open the door, get on the floor —

everybody do the dinosaur. 🦕
