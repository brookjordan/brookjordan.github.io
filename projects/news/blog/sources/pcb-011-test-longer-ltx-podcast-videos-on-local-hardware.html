longer-video test contract

PCB-011 Test longer LTX podcast videos on local hardware

Question

How much longer can the native LTX-2.5 podcast video run reliably on the Apple Silicon hardware now that the video models and generation path are local?

Scope

The current production graph uses six still-image frames and 49 frames per LTX transition at 25 fps before stitching. The test varies transition count and, separately, transition length. The current settings remain the control. Speech still uses VibeVoice; YuE2 and native LTX-2.5 handle music and video. This ticket tests the video duration limit without changing production first.

Acceptance criteria

  • Establish a control run with the current six-frame / 49-frame-transition configuration.
  • Test at least two longer-duration configurations without reading LTX models from the NAS during generation.
  • Record wall time, peak memory, local model state, output duration, frame count, decoded-video validity and guide-frame preservation.
  • Confirm ComfyUI returns cleanly to the normal profile after each run and the n8n lock is released.
  • Identify a safe production limit and the point where runs begin to fail.
  • Do not increase production duration until a fresh publication-disabled run passes and someone has reviewed the output.
