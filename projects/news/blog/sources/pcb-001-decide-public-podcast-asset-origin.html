PCB-001 · Decide public podcast asset origin

Question

Where should durable podcast MP3, MP4, and PNG assets live and how should public pages reference them without growing the GitHub publication request indefinitely?

Resolution

Use the NAS HDD as the durable asset store at /volume2/assets/podcast, served publicly from assets.brook.dev through a narrowly scoped read-only service behind Nginx Proxy Manager and Cloudflare. Keep only lightweight page metadata in the GitHub Pages repository.

The current GraphQL publisher failed reproducibly at an 8.8 MB base64 payload but reached GitHub normally with a single 2.05 MB asset, so this decision removes large binaries from that transport path rather than depending on batch sizing.

Evidence

  • The 2026-08-17 n8n diagnostic replay reproduced HTTP 499 for the complete GraphQL payload and received GitHub’s normal STALE_DATA response for the smaller control requests.
  • the PodCast Builder project map records the approved delivery split.
