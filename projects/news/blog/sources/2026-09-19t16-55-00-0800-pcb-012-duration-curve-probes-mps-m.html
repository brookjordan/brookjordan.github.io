Memory envelope facts

  • The normal/ltx comfy-profile wrapper sets PYTORCH_MPS_HIGH_WATERMARK_RATIO=0.8, capping MPS at ~22.46 GiB on this 36 GB machine. The LTX-013 launch contract names 0.0 but the wrapper did not apply it; probes ran both ways.
  • Failure mode is deterministic, not stochastic: both capped 250f attempts requested the identical +1.83 GiB at the same phase (~6 min in, early sigma steps = peak attention allocation). Freeing desktop memory did not help; the deficit is inside the MPS cap.
  • Uncapped 250f: sampler plateaued at 7.6–9.4 GiB server-free for the whole sampling phase (flat slope, −5.7 MB/s); no swap growth; CPU near-idle (GPU-bound). Second memory event is the tiled VAE decode at the end.
  • Uncapped server was launched as a bare process with the env var applied (wrapper hard-codes the value); pcb012-uncapped.log in ComfyUI-Shared/user/logs.
  • Time scaling linear above the load phase: 49f→602 s, 121f→1053 s, 250f→2196 s (8.8 s/frame wall).

Quality observations (fog-motion artefact)

  • Measured fog centroid (bright-pixel threshold, 2 fps samples): 10 s run drifts continuously 0.355→0.444 (normalised y) with coverage 0.52→0.67, then snaps back to 0.392 in the final half-second — the model warping fog to satisfy the end keyframe.
  • 5 s run is worse: mid-clip reversal (0.304→0.411) plus end snap. Endpoint interpolation on amorphous elements (fog/smoke) produces global shape-morphing rather than local motion.
  • Community/official mitigations identified: Motion Control IC-LoRA (sketched point trajectories), AInVFX fluid IC-LoRA (paint blobs → smoke/fire, LTX 2.5, free), prompt-side ambient-not-directional phrasing (weak), and the two-part arm (shorter interpolation arc per render).
  • MLX context: ComfyUI-LTXVideo-mlx node was import-broken at pipeline-build time (LTX-001 note) and is excluded from the ltx profile; GGUF+MPS was proven and frozen instead. MLX memory/speed profiles differ — envelope numbers here are MPS/GGUF-specific and do not transfer.
