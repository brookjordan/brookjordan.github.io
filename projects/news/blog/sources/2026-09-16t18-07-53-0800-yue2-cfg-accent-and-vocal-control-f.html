YuE2 CFG behaviour and documented experiment

YuE2 CFG, accent and vocal-control findings

This packet records what YuE2 can and cannot be told about vocal character, accent, backing vocals and chorus prominence. It was verified on 2026-09-16 against the official repository's agent skill and generation guide, and against the local yue2.cpp source. It is a source summary; the current project decisions live on the map.

Classifier-free guidance is off by default

Semantic CFG defaults to 1.0 in full and melody mode and 1.01 in off mode. A scale of exactly 1.0 keeps a single branch, which means the protocol applies no guidance at all and the style and lyric text act as conditioning only. The official guidance for an explicit experiment is cfg_scale=1.2, and it states plainly that this is "not a guaranteed quality improvement". ABC generation itself has no CFG.

With a score, the negative branch keeps the same instruction and the exact ABC while dropping the style and the lyrics, so guidance pulls the render toward the requested text. In the local runtime this is yue2_default_guidance in src/prompt.h, guided = cfg_scale != 1.0f in src/generate.h, and the resolution at pipeline.h line 266 (r.cfg_scale < 0.0f ? default : r.cfg_scale). The request field is cfg_scale, whose default of -1 means "apply the protocol default".

Practical consequence: the local yue-synth CLI exposes no --cfg-scale flag, so guidance can only be enabled by setting cfg_scale in the request JSON. Every earlier local render therefore ran unguided — the first smoke test, the Quinn takes and the first two Henry and Kaitlyn takes all logged CFG=1.00.

Accent has no supported hard control

The official skill is explicit that there is no request field for reference_audio, phonemes, bpm, negative_prompt, an edit interval, or a reference singer, and that pronunciation and note-alignment instructions "are not hard conditioning inputs" and belong in validation sidecars. This confirms and strengthens the earlier prompt-guidance note's British-accent conclusion: accent fidelity can only be soft-conditioned through style wording and must be judged by listening. There is no supported way to force a specific accent, and no negative-prompt field, so exclusions such as no weak thin vocal must live inside the style string as ordinary tags.

Where vocal direction belongs

Put genre, instruments, vocal character, language and intended tempo in style. Put section tags and the actual words in lyrics, and keep implementation notes out of the lyrics. tags is an alias for style, and the two must agree if both are sent. A replacement instruction must not be pasted into the style prompt, because the modes already select native instructions.

There is no dedicated field for backing vocals or for lead-vocal prominence. Both must be expressed as style wording that names the lead's dominance, the backing vocal role and its placement, and the competing interpretations to exclude. Whether the effect is realised is a listening judgement.

Budget, preset and truncation

The standard preset is BF16 AR/NAR, an FP32 VAE, 32 midpoint synthesis steps and context 24576. The semantic stage has a preset ceiling of 9000 frames, which is 360 seconds at the 25 frame-per-second rate; a larger requested duration is clamped to that ceiling because the shorter of the two wins. A song can still emit its end token and finish well before the ceiling, so a large requested duration is a safety margin rather than a target.

status="complete" does not imply an untruncated song. Both the ABC and semantic truncation flags must be inspected, and the local runtime prints (truncated) on the semantic stage when it hits the budget. This refines the note in the Quinn takes ticket that the local wrapper "does not expose the official truncated flags": the wrapper does not surface them, but the render log does.

Decoder roles and the official skill

YuE2-Vae is the listening/default decoder and YuE2-Vae-legacy is the benchmark-protocol decoder; the two must be kept separate and their roles not inferred from the word "legacy". The local YuE2-Vae-F32.gguf is the listening decoder.

The upstream repository ships the canonical agent skill at skills/yue2-music/SKILL.md, with references for generation-and-covers, models-and-setup, listening-and-evaluation, abc-editing and editing-workflows, plus run_yue2.py, listen.py, transcribe.py, abc_tools.py and an assets/prompt.json example. This is the source that earlier project notes referred to as "the yue2-music skill references" but which was not present on local disk.

A loudness observation

The v0.1 folk render measured flat across the song: RMS between −13 and −15 dBFS in every 8-second window with peaks at or near 0 dBFS. The perceived weakness of its chorus is therefore a masking and arrangement effect rather than a level drop, so level-riding or normalisation post-processing will not fix it. See the v0.1 render packet.
