PCB-003 · Split podcast publication between NAS and GitHub

Scope

Update n8n so final hydrated media is written to the NAS asset service before publication. Build pages with assets.brook.dev media URLs and send only the episode HTML, site index, and menu metadata through the GitHub publication path.

The page publication must be gated on successful NAS writes and preserve a recoverable manifest for retries.
