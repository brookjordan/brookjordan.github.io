Ethernet endpoint correction

Raw conversation — Ethernet endpoint correction

Date: 2026-09-15 Project: PodCast Builder project map Related ticket: PCB-007

User report

Execution 2524 failed after 1h 52m at TEST — YuE2 synth:

connect ECONNREFUSED 100.84.158.31:8087

Verification

The MacBook has direct Ethernet interface en16 at 10.10.10.1; the NAS is 10.10.10.2 on the same direct network. The old YuE2 request used the NAS serviceHost, which was the wrong host role for the MacBook-side YuE2 service.

The MacBook's Ollama port was open on 192.168.0.25:11434 during the check. ComfyUI 8188 and YuE2 8087 were not listening at that time, so service-start and reachability checks remain required before retrying.

Change

The workflow's LLM config now selects the LAN profile:

networkLocation = LAN
serviceHost = 10.10.10.2
comfyHost = 10.10.10.1
comfyPort = 8188

TEST — YuE2 synth now uses comfyHost:8087, keeping the MacBook media endpoint explicit without conflating it with llmHost/Ollama.

Read-back verified 99 nodes and 98 connections, with no remaining YuE2 URL using serviceHost.
