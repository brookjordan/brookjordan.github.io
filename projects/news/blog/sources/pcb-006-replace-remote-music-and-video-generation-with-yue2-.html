PCB-006 Replace remote music and video generation with YuE2 and native LTX-2.5

Outcome

The podcast builder now uses local YuE2 for the musical segment and native Apple Silicon LTX-2.5 for image-to-image transitions. The old remote-generation path is retained only as rollback. Local LTX model transfer and reliability hardening continue under PCB-008.

Current evidence

  • Native LTX-2.5 smoke generation completed under the isolated ltx profile on ComfyUI 0.35.0.
  • The corrected smoke output decoded as nine frames at 512 × 320 and preserved both guide endpoints.
  • LTXVCropGuides now sits between sampling and VAE decode, preventing guide padding from increasing a requested 49-frame transition to 65 frames.
  • The ltx profile uses a separate database and loads ComfyUI-GGUF while excluding the incompatible ComfyUI-LTXVideo-mlx node.
  • Switching from ltx back to normal was exercised successfully; VHS_LoadVideoPath and VHS_VideoCombine were registered after restoration.
  • Inactive duplicate 2k7x4U8GgLeSFpRE uses one execution ID throughout profile ownership, performs isolated-profile model/node preflight, restores normal before stitching, and remains inactive.
  • Execution 2491 proved YuE2 generation and materialisation: intro_2491_00001.wav is a readable 2,303,788-byte, 11.999-second WAV. Collate intro song failed because it requested the obsolete .mp3 filename.
  • Collate intro song, the disabled trim command, and Prepare final media manifest use the same .wav filename contract. Collate intro song reads YuE2 output from music port 8189; Download final media reads shared output from normal port 8188.
  • Controlled execution 2497 fetched the corrected WAV through n8n and read all 2,303,788 binary bytes from database binary storage. It then exposed the limitation of retrying an old execution: cached pending work used the old graph, so later checks use fresh side-effect-free executions instead.
  • Execution 2491 completed its native transition, normal-profile restoration, VHS stitch, and final video retrieval before the parallel music branch failed. Its requested transition is 49 frames at 1280 × 704 and its first and last decoded frames preserve their corresponding guide images.
  • Side-effect-free execution 2502 exercised the saved Label intro song, Prepare final media manifest, Download final media, and Normalise final media nodes against the real 2491 artefacts. It read 30 database-backed binaries totalling 9,329,116 bytes: one WAV, 26 MP3s, two PNGs, and one MP4.
  • Fresh full execution 2503 exposed a profile race. The video branch restored normal ComfyUI at 08:48:00, then the parallel YuE2 branch switched to music at 08:48:20. Finalise podcast media waited for both branches, but the old graph went directly to publication preparation, so Download final media reached dead port 8188 and received ECONNREFUSED.
  • The duplicate now routes Finalise podcast media through Restore normal ComfyUI before final media and Assert normal ComfyUI before final media before publication preparation. This post-merge barrier uses the same execution lock and proves port 8188, VHS_LoadVideoPath, and VHS_VideoCombine before any final-media request.
  • Side-effect-free execution 2505 started with music listening on 8189 and nothing on 8188. The new barrier started normal ComfyUI on 8188, passed its assertion, and then downloaded and normalised all 30 binaries totalling 9,329,116 bytes.
  • An n8n editor autosave made during execution 2503 reverted the saved duplicate to its stale .mp3/port configuration and removed one non-functional TODO sticky note. The functional corrections were reapplied and read back. Reload the editor before making manual changes so its cached graph cannot overwrite the saved workflow again.
  • Production S9v0UpCVYcrtVJH4 was not modified or manually invoked during this repair. Its execution history nevertheless records scheduled trigger execution 2493, started at 2026-09-14T20:30:35.096Z; do not describe production as wholly unexecuted. The duplicate is an inactive 99-node graph, passes its LTX, stitching, WAV, port, and post-merge lifecycle validator, and leaves the ComfyUI lock clear.
  • The YuE2 synth request no longer sends the 12-second duration cap. The song brief still asks for roughly 20 to 40 seconds, allowing YuE2 to end naturally. Its native 9,000-token semantic ceiling remains the six-minute safety bound. The disabled Trim intro silence node removes trailing silence only and does not impose a fixed duration. WAV generation, .wav retrieval on 8189, the final-media manifest, and retrieval on 8188 remain unchanged.

In the local yue2.cpp port that default is 1.0, which keeps a single branch and applies no guidance at all, so the style tags condition a render only weakly. Enabling it requires cfg_scale in the request JSON, because the CLI exposes no --cfg-scale flag; the upstream documented experiment value is 1.2. Confirm the 9,000-token ceiling independently before changing either value. Detail: the YuE2 CFG and vocal-control findings packet.

Resolution — 2026-09-19

The cutover is complete in production workflow 2k7x4U8GgLeSFpRE (Podcast – latest). YuE2 replaces the former music generator, and native LTX-2.5 replaces the former video-generation path. The previous builder remains inactive as rollback. The first full production run completed 98/98 nodes green and published an episode.

The remaining work is not part of this cutover ticket: PCB-008 owns local LTX model transfer and NAS independence; new podcast tickets own longer-video testing and replacement of VibeVoice.

Deferred follow-ups

The original cutover acceptance items below are no longer blockers for the completed generator replacement. Their remaining work is tracked separately:

  • Longer finished-video configurations: PCB-011.
  • Production TTS replacement and audio verification: PCB-009 and PCB-010.

Known constraint

The shared Python environment still reports mlx-lm 0.31.3 requiring transformers>=5.0.0 while transformers 4.57.6 is installed. Do not upgrade blindly: the isolated profile avoids the incompatible MLX node, and dependency changes need profile-specific evidence.
