TTS replacement scope

PCB-009 Replace VibeVoice with maintained local TTS

Current production evidence

As of 2026-09-19, n8n workflow 2k7x4U8GgLeSFpRE (Podcast – latest) is active with 102 nodes and matching draft/published version IDs. Its Generate audio node still submits VibeVoiceSingleSpeakerNode, so this ticket is a real production replacement rather than a completed migration.

Scope

Compare a small cohort from the local speech-generation project. Include a voice-cloning model and a small named-voice model. Start with Chatterbox, IndexTTS, Supertonic 3 and Kokoro. Keep VibeVoice as the baseline, not the target.

The comparison must cover maintenance and licence status, Apple Silicon support, voice-cloning method, speaker consistency, long-form stability, latency, memory, audio validity, language coverage and the work needed to call the model from n8n.

Acceptance criteria

  • Pin the exact upstream code and model revisions and record licence constraints.
  • Generate the fixed podcast test corpus locally with each selected candidate.
  • Verify every output is non-empty and decodable.
  • Measure quality, latency, memory, long-form behaviour and speaker consistency.
  • Select a replacement and record the reason, limitations and rollback path.
  • Integrate the selected system in a duplicated n8n workflow before changing production.
  • Keep VibeVoice available as rollback until a complete replacement run passes.
