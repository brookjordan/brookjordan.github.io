PCB-014 motion-control scope

PCB-014 Evaluate IC-LoRA control for fog and fluid motion

Question

Do the Motion Control IC-LoRA or the AInVFX fluid IC-LoRA remove the fog/smoke motion artefacts (mid-clip reversal, final-frame snap) that FLF2V endpoint interpolation produces on amorphous elements, at acceptable quality on the local MPS path?

Evidence motivating the question

Measured on the PCB-013 case C renders (see the probe packet):

  • 10 s render: fog centroid drifts continuously then snaps back in the final half-second — the model warping the fog to satisfy the end keyframe.
  • 5 s render: mid-clip reversal (fog moves down, reverses up) plus the same end snap; coverage swings 0.46→0.65.
  • Both match Brook's visual report ("smoke flying up and then down again, not drifting naturally").

Community/official mitigations to evaluate:

  1. Motion Control IC-LoRA (official, ltx-2.3-22b-ic-lora-motion-track-control-ref0.5): sketched sparse point trajectories; the LoRA follows paths instead of interpolating keyframe states. Docs: https://docs.ltx.io/open-source-model/feature-guides/structural-control/motion-control.md
  2. AInVFX fluid IC-LoRA (free, rank-32 654 MB, LTX 2.5): painted blobs on keyframes → animated smoke/steam/fire matching shapes. Trained on smoke/steam/fire only. https://huggingface.co (ainvfx-fluid) + ready ComfyUI workflow.
  3. Two-part arm with matched endpoints (shorter interpolation arc) — already part of PCB-012's planned arms; compare rather than re-test.

Scope guards

  • Evaluation happens after PCB-012's frozen-recipe experiment completes; no IC-LoRA variables inside PCB-012's 15-render matrix.
  • Compute budget: two control renders (one per LoRA) on the case C pair, judged against the plain case C 10 s render, before any wider use.
  • MPS memory cost of each LoRA must be recorded (PCB-013 showed the 250f uncapped ceiling; a LoRA on top may reduce it).
  • MLX is out of scope here; see the operating-envelope packet's MLX note.

Acceptance criteria

  • Both LoRAs run (or fail with recorded cause) on the case C pair at 250 frames.

  • Fog-motion artefact measured with the same centroid/snap metric as the plain render.

  • Recommendation recorded: adopt per-episode, adopt for fluid cases only, or reject.
